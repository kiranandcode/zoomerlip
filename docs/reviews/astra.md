## Security and user safety

1. **High — Removing an account in one tab can restore its saved credentials from another.** Each tab reads accounts once. Adding or removing an account replaces the entire stored list from that tab’s React state. The second tab also keeps its event queue and signed-in workspace active after removal. Observed with two synthetic account snapshots. Removing account 1, then adding account 2 from the older snapshot, persisted both accounts. Synchronize removals across tabs, dispose the affected sessions, and serialize updates against current storage. Cover this exact two-tab sequence. Evidence in `src/App.tsx:63`, `src/App.tsx:72`, `src/App.tsx:88`, `src/App.tsx:96`, and `src/api.ts:150`.

2. **High — Losing access leaves private history visible.** Subscription changes replace the channel directory while the selected channel and message/profile caches survive. A terminal 401 also updates only connection status. Even a failed history refresh retains the old message array. Someone removed from a private channel can continue reading previously rendered content in the open view. Purge affected messages from channel, topic and profile caches, clear associated topic data, and leave inaccessible views. Lock the workspace and clear its sensitive snapshots on terminal authentication failure. Test with previously populated data and a denied refresh. Evidence in `src/useSession.ts:116`, `src/useSession.ts:162`, `src/App.tsx:203`, `src/App.tsx:534`, and `src/cache.ts:243`.

3. **High — Zoomerlip displays messages from muted users and increments the background badge.** Registration omits mute state and mute events. Conversation and profile views render the sender and content directly. The badge increments on every incoming background message regardless of the server’s read flag. An account’s moderation preference disappears when switching clients. Fetch and subscribe to muted-user state, apply it to history, new events, profiles and member lists, and derive unread state from server flags. Test both a pre-existing mute and a mute applied during a session. Evidence in `src/useSession.ts:61`, `src/useSession.ts:143`, `src/App.tsx:238`, `src/App.tsx:836`, and `src/components/ProfilePage.tsx:137`. [Zulip mute behavior](https://zulip.com/help/mute-a-user) · [Zulip message events](https://zulip.com/api/get-events#message)

4. **Medium — Local test secrets sit inside Vite’s served project root.** The harness writes account credentials and service secrets under the repository. Vite’s project-root static middleware uses its filesystem deny list, and the configuration adds no rule for these files. Git ignores and owner-only file modes still allow the same-user dev server to read them. Exposure requires access to the running development server. Move generated credentials outside its served tree or explicitly deny the complete local fixture directory while preserving Vite’s existing restrictions. Verify using a harmless sentinel. Evidence in `scripts/seed-local.mjs:167`, `scripts/setup-local.mjs:16`, `.gitignore:5`, `vite.config.ts:5`, and installed `node_modules/vite/dist/node/chunks/config.js:22664` and `:25960`.

5. **Medium — Closing Add organization can still sign the account in.** The close control remains enabled during authentication. A late successful promise still calls the original login callback, persists the key, and switches organizations after dismissal. Invalidate the submit operation on close or unmount, pass cancellation through login, and guard the commit. Test dismissal before the identity response returns. Evidence in `src/components/Login.tsx:63`, `src/components/Login.tsx:80`, `src/api.ts:119`, and `src/App.tsx:87`.

6. **Medium — Private and public channel destinations look identical during composition.** The model contains `invite_only`, but navigation and the active header always show the same hash. Posting sensitive content after selecting a similar public channel has no visible audience cue. Label private channels in the sidebar and active composer/header, including an accessible name. Evidence in `src/types.ts:25`, `src/App.tsx:348`, `src/App.tsx:496`, and `src/App.tsx:656`.

## Cache and event ordering

7. **High — Recovery accepts pages and topic responses from the expired queue.** Invalidation aborts newest-history requests only. Pagination and topic requests use separate controllers, and their completions have no generation check. Observed a fresh history containing ID 30 followed by an old pagination response producing IDs 10 and 30 and clearing the older-pages flag. A pre-recovery topic response was also reused and marked fresh for five minutes. Track an account generation and a per-view pagination anchor. Reject superseded results and restart currently observed topics. Evidence in `src/cache.ts:258`, `src/cache.ts:293`, `src/cache.ts:398`, `src/cache.ts:415`, and `src/cache.ts:449`.

8. **High — The 2,000-event replay limit can restore a deleted message.** A request records its start sequence but cannot detect that the journal has dropped an event it needs. Observed a delayed response restoring deleted ID 7 after 2,000 subsequent events. The same replay assumption is used by pagination and topics. Record the oldest available sequence and discard/refetch incomplete results, or retain required events for each outstanding request. Evidence in `src/cache.ts:206`, `src/cache.ts:227`, `src/cache.ts:285`, `src/cache.ts:388`, and `src/cache.ts:430`. Zulip also uses deletion events for messages the account loses access to. [Zulip deletion events](https://zulip.com/api/get-events#delete_message)

9. **Medium — A move or deletion during a topic fetch can leave an expanded list stale indefinitely.** The event notifies subscribers before the fetch finishes. The subscriber can rejoin that same promise. Completion writes the old list with a zero timestamp but sends no further notification. The workspace then displays it until another event or navigation occurs. Schedule one fresh read when an in-flight topic request was invalidated. Evidence in `src/cache.ts:376`, `src/cache.ts:415`, `src/cache.ts:441`, and `src/App.tsx:213`.

10. **Medium — A moved topic or a late send can redirect composition incorrectly.** After a topic move the cache refreshes, but the selected view and read-only compose target retain the old name. A later send can recreate the old thread. Separately, a pending new-thread send that completes after navigation calls the workspace-wide selector and takes the user out of her newly selected conversation. Reconcile the compose destination on applicable moves, and follow a completed send only if its initiating view is still active. Evidence in `src/cache.ts:389`, `src/App.tsx:535`, `src/App.tsx:659`, `src/App.tsx:668`, and `src/App.tsx:1151`. [Zulip topic-move semantics](https://zulip.com/api/get-events#update_message)

## Browser-stored themes and accessibility

11. **Medium — A theme can make the editor unreadable while its contrast indicator reports 18.9:1.** Observed with an imported palette. The indicator measures only message text against the message surface. The editor immediately applies the palette to the whole document, including its own input text, fields, and recovery controls. In the fixture the input text and background both became the same gray, yielding 1:1. The stored palette reapplied after reload. Separately, for a mid-gray accent the automatic button ink choices yield 3.95:1 and 4.18:1. Keep the editor and reset action legible during preview, check functional color pairs, and choose a sufficient-contrast button foreground. Evidence in `src/components/CustomThemes.tsx:46`, `src/components/CustomThemes.tsx:117`, `src/components/CustomThemes.tsx:271`, `src/customThemes.ts:109`, `src/theme.css:1257`, and `src/main.tsx:13`.

Closing and reopening the editor reads the old storage value, which the child effect reapplies. Reset also ignores the write result. Keep the current session preferences above the dialog and surface failed reset writes. Evidence in `src/appearance.ts:60`, `src/components/Appearance.tsx:7`, `src/components/Appearance.tsx:139`, and `src/components/CustomThemes.tsx:46`.

13. **Medium — Built-in palettes have low-contrast text.** Calculated ratios from the declared colors were 2.69:1 for the graphite login placeholder, 2.66:1 for the light-theme API-key instructions, and 1.37:1 for the light-theme storage-error toast. These are small functional text. Use theme-aware foreground/background pairs and check their effective contrast in every preset. Evidence in `src/style.css:1046`, `src/style.css:1068`, `src/style.css:1117`, `src/theme.css:7`, `src/theme.css:35`, and `src/theme.css:993`. [W3C text contrast guidance](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

14. **Medium — Add organization allows keyboard focus to escape behind the dialog.** The overlay declares itself modal but leaves the workspace interactive, with no focus containment, Escape handler or restoration. Reuse the named native dialog already used for Appearance and verify Tab, Shift+Tab, Escape and return focus. Evidence in `src/App.tsx:164`, `src/components/Login.tsx:80`, `src/components/Login.tsx:93`, and `src/components/Appearance.tsx:24`.

15. **Medium — The mobile channel drawer covers its own toggle.** At widths up to 640 px the drawer starts at the same horizontal position as the main pane and overlays its header. It has no close button, Escape handler or dismissible backdrop. The rail’s Home action changes views without closing it. ## Performance

16. **Medium — Directory changes block event delivery behind repeated full reloads.** Every subscription, realm or member event awaits both the full user list and the current subscription list before proceeding. Ten such events trigger twenty requests, even for a single-member update. Each replacement also sorts the member list. Apply event deltas by ID or coalesce necessary refreshes per batch. Test request counts with a burst and a slow directory response. Evidence in `src/useSession.ts:110`, `src/useSession.ts:121`, and `src/App.tsx:238`.

17. **Medium — A single topic move scans all cached messages for each view.** The code collects all known messages, then runs the reducer on every one for every view. One synthetic move across 24 views with 60 distinct messages each made 36,025 membership checks for one moved ID. Larger move lists add linear ID searches. Build a set of affected IDs once, transform each affected message once, and update the source and destination views. Evidence in `src/cache.ts:75`, `src/cache.ts:313`, `src/cache.ts:322`, and `src/cache.ts:330`.

18. **Medium — Long histories make typing and private-image loading scale with the entire conversation.** Each keystroke rerenders all message rows, rebuilds reaction groups and reformats dates. Active histories grow on each older-page request. Each mounted private image also requests a signed URL and eagerly loads the full original, including offscreen profile cards. Isolate composer updates, memoize or window message rows, and start bounded image resolution when a preview approaches the viewport. Test typing and attachment request counts after repeated pagination. Evidence in `src/App.tsx:588`, `src/App.tsx:836`, `src/App.tsx:848`, `src/cache.ts:293`, `src/content.ts:93`, and `src/components/MessageContent.tsx:34`.

## Custom theme editor and persistence

19. **Medium — Edits can restore a palette deleted in another tab.** The library now refreshes on storage events and re-reads before saving. The open draft remains live after its source is removed. Saving the edited copy appends it as a new record with the deleted ID. Two truly simultaneous read-modify-write operations also lack serialization. Distinguish creating from editing, detect deletion/revision conflicts, and offer to save a copy under a fresh ID. Evidence in `src/components/CustomThemes.tsx:38`, `src/components/CustomThemes.tsx:63`, and `src/components/CustomThemes.tsx:157`.

20. **Medium — Appearance controls can report changes the preview ignores.** With a custom theme active, selecting Coral marked the swatch pressed while the applied accent stayed the saved gray. During an open draft, changing the base preset or pressing Reset also leaves that draft applied on top. Define which control owns the preview. Disable irrelevant swatches or update the custom accent, and end the draft when resetting or explicitly selecting another palette. Evidence in `src/components/Appearance.tsx:59`, `src/components/Appearance.tsx:83`, `src/components/Appearance.tsx:139`, `src/components/CustomThemes.tsx:46`, and `src/customThemes.ts:113`.

21. **Low — Duplicate stored IDs alias separate palettes.** The storage reader validates each ID’s characters but accepts repeated IDs. An isolated read restored two records with the same ID. Selection uses the first match, saving edits replaces both, and deletion removes both. Deduplicate during recovery and enforce identity uniqueness when writing. Evidence in `src/customThemes.ts:50`, `src/appearance.ts:56`, `src/components/CustomThemes.tsx:64`, and `src/components/CustomThemes.tsx:78`.

22. **Low — A late file read can replace a newer draft.** Import waits for file text before setting the draft. An earlier read completing after another import or after beginning a different edit can replace the newer choice. Track the current edit/import operation and ignore superseded completions. Evidence in `src/components/CustomThemes.tsx:99`, `src/components/CustomThemes.tsx:157`, and `src/components/CustomThemes.tsx:182`.
